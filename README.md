# مجموعة العون — نموذج بصري أولي

هذا المستودع يطبّق **الخطوة الموصى بها في وثيقة القرارات v1.1 (§٨)**: نموذج بصري
لصفحتين فقط (الرئيسية + قالب صفحة مجال ممارسة، بالعربية والإنجليزية) — **قبل** بناء
نظام المكوّنات والموقع كاملًا. ليس المقصود منه أن يكون الموقع النهائي.

## الحالة مقابل وثيقة القرارات

| القرار | الحالة هنا |
|---|---|
| المكدس التقني (§٤) | ✅ Next.js App Router · JS+JSDoc (`checkJs`) · next-intl · CSS Modules بخصائص منطقية · بلا ORM |
| نظام الألوان (§٢) | ✅ منسوخ حرفيًا في `src/app/tokens.css`، مع تطبيق القواعد الصارمة الست |
| الخطوط (§٣) | ⚠️ IBM Plex Sans (لاتيني) متغيّر فعليًا. **IBM Plex Sans Arabic لا نسخة متغيّرة له على Fontsource** — استُخدمت أوزان ثابتة (400/600/700) بدلًا منه؛ يحتاج قرارًا لاحقًا إن أردنا مصدرًا آخر للنسخة المتغيّرة العربية |
| `letter-spacing: 0` على العربية دائمًا | ✅ مطبّق في `globals.css` |
| الوضع الداكن | ❌ **غير مُفعَّل عمدًا.** سلوك القوس على الخلفية الداكنة (`#0E1423`) غير محسوم من العميل [CLIENT APPROVAL REQUIRED] — راجع §٦.٣. لا تضف Dark Mode قبل حسم هذا السؤال |
| الشعار | ⚠️ **لا يوجد ملف شعار حقيقي في هذا التسليم.** `ArcMark` في `src/components/ArcMark.js` تمثيل هندسي مؤقت لعنصر القوس فقط لإثبات الموضع، **وليس** شعار العميل. استبدله فور توفر SVG حقيقي بمسارات (البند الحاجب §٦.١) |
| المحتوى (§٩) | ✅ لا اسم محامٍ ولا رقم ولا إنجاز ولا مجال ممارسة مُختلَق. كل حقل محتوى مهني حقيقي موسوم `[CONTENT REQUIRED]` في `messages/ar.json` و`messages/en.json` |
| الاعتماديات (٧ كحد أقصى) | ✅ 6 مستخدَمة: `next`, `react`, `react-dom`, `next-intl`, `@fontsource-variable/ibm-plex-sans`, `@fontsource/ibm-plex-sans-arabic` — يبقى سلوت واحد لاحتياج لاحق (مثلًا Supabase client) |

## البنية

```
src/
  app/
    tokens.css            ← توكِنز الهوية (لا تُعدَّل هنا؛ المصدر وثيقة القرارات)
    globals.css            ← أساسيات + خصائص منطقية (بلا ملف RTL منفصل)
    [locale]/
      layout.js             ← lang/dir حسب اللغة + الخطوط + المزوّد
      page.js                ← الصفحة الرئيسية
      practice-areas/[slug]/ ← قالب صفحة مجال ممارسة (slug الوحيد حاليًا: placeholder)
  components/               ← SiteHeader, SiteFooter, ArcMark, GradientRule
  i18n/                      ← routing.js, request.js, navigation.js (next-intl)
messages/
  ar.json / en.json          ← كل النصوص، بما فيها وسوم [CONTENT REQUIRED]
middleware.js                 ← توجيه اللغة (ar افتراضية، en ثانوية)
```

## تشغيل محلي

```bash
npm install
npm run dev
# افتح http://localhost:3000 (يُحوَّل تلقائيًا إلى /ar)
```

للتحقق من بناء الإنتاج (تم التأكد أنه ناجح عند إعداد هذا التسليم):

```bash
npm run build
```

## البنود التي لا تزال تحجب الانتقال للمرحلة التالية (من §٦)

هذه غير محلولة في هذا التسليم عمدًا — تحتاج قرار/أصل من العميل قبل المتابعة:

1. ملف شعار متجهي حقيقي (مسارات قابلة للتحرير، لا صورة نقطية ملفوفة في SVG).
2. نسخة Knockout كاملة تعمل فعليًا على الخلفية الداكنة الجديدة.
3. **قرار العميل**: هل اختفاء القوس على الداكن مقصود أم عيب بالملف؟
4. الشعار النصي وصيغ التركيب عربي/إنجليزي.
5. قائمة مجالات الممارسة المعتمدة.
6. بيانات التواصل الكاملة، والنطاق/DNS.

## رفع المشروع إلى GitHub وربطه بـ Vercel — خطوة بخطوة

> ملاحظة أمان: لا تشارك أي *token* أو كلمة مرور معي في المحادثة أبدًا. الأوامر التالية
> تستخدم مصادقتك الشخصية على جهازك (متصفح GitHub أو `gh auth login` أو مفتاح SSH).

### الخيار أ — عندك مستودع GitHub فارغ بالفعل (نفس الرابط اللي بعتّه)

الرابط اللي أرسلته يرجّع 404 حاليًا، يعني إما لسه ما انبنى أو خاص. أول شي تأكد إنه موجود:

1. افتح https://github.com/new
2. الاسم: `Al-Aoun-Law-Firm-Legal-Consultations` (أو أي اسم تفضّله)
3. **لا** تفعّل "Initialize with README" (عشان ما يصير تعارض مع اللي عندنا)
4. أنشئ المستودع

### الخيار ب — ربط هذا المشروع محليًا ورفعه

نفّذ هذي الأوامر من داخل مجلد المشروع (بعد ما تحمّل الملفات من هذا الرد):

```bash
cd al-aoun-site

git init
git add .
git commit -m "نموذج بصري أولي: الرئيسية + قالب مجال ممارسة (ar/en)"

git branch -M main
git remote add origin https://github.com/LAPASSIIOON/Al-Aoun-Law-Firm-Legal-Consultations.git
git push -u origin main
```

لو ظهر خطأ مصادقة، سجّل دخولك أول مرة بـ:

```bash
gh auth login
# أو استخدم Personal Access Token عند طلب كلمة المرور (وليس كلمة مرور حسابك الفعلية)
```

### ربط Vercel (بعد الرفع لجيت هب)

**عبر الواجهة (الأسهل):**
1. افتح https://vercel.com/new
2. اختر "Import Git Repository" وحدّد المستودع
3. Vercel يكتشف Next.js تلقائيًا — لا إعدادات إضافية مطلوبة لهذا النموذج
4. اضغط **Deploy**

**أو عبر CLI:**
```bash
npm i -g vercel
vercel login
vercel        # نشر تجريبي (preview)
vercel --prod # نشر إنتاجي
```

بعد كل `git push` جديد على `main`، Vercel ينشر تلقائيًا لو ربطت المستودع من الواجهة.
